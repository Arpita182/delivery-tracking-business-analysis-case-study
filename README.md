# Delivery Tracking Enhancement — Business Analysis Case Study

## Project Overview

This is an independent Business Analysis case study focused on improving delivery tracking visibility in a quick-commerce mobile application.

The case study identifies a customer experience problem in the current delivery tracking journey, analyses the existing process, and proposes a future-state solution that provides customers with real-time delivery partner location and improved ETA visibility.

The project demonstrates an end-to-end Business Analysis workflow from problem identification and process analysis to requirements definition, use cases, wireframes, and UAT.

---

## Problem Statement

During the delivery stage, customers may have limited visibility into the delivery partner's current location. The existing experience primarily provides an estimated delivery time/countdown, which may not always give customers a clear understanding of where their order is or how close the delivery partner is.

This lack of real-time delivery visibility can create uncertainty and frustration, particularly when the displayed ETA changes or is not sufficiently accurate.

---

## Proposed Solution

Introduce a real-time delivery tracking capability that allows customers to:

- View the delivery partner's current location on a map.
- Track the delivery partner's movement during the delivery.
- View an updated ETA based on the latest available location information.
- Receive location and delivery status updates.
- Handle cases where real-time location data is temporarily unavailable.

---

## Business Analysis Objectives

- Identify the current-state delivery tracking gap.
- Analyse customer pain points and their potential business impact.
- Define the proposed future-state process.
- Document business and functional requirements.
- Create user stories and acceptance criteria.
- Model system and user interactions using a use case diagram.
- Design low-fidelity wireframes for the proposed experience.
- Define UAT scenarios and test cases.
- Demonstrate an end-to-end BA approach using a practical product problem.
